# Japanese N5 Vocabulary Trainer

A Japanese–Bengali vocabulary learning app for JLPT N5 learners.

## Overview

This project helps learners study Japanese vocabulary with Bengali meanings. The vocabulary data is maintained in `src/data/vocabulary.ts`.

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Zustand

## Run locally

Make sure Node.js (LTS) and npm are installed.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Build

```bash
npm run build
npm run preview
```

The production build is generated in the `dist/` directory.

## Deployment

The app is configured for GitHub Pages at:

https://j-baki.github.io/Japanese_N5_vocabulary/

GitHub Pages deployment is handled by the workflow in `.github/workflows/deploy.yml`.
